# Solvability

Solvability is a research-informed learning platform designed to help users retain previously learned material over time.

It uses personalised 20–30 minute assessments to encourage active recall and help users maintain fluency across the subjects they want to retain.

## Live Demo

[Try Solvability](https://solvability.base44.app)

## Key Features

- Personalised retention-focused assessments
- 20–30 minute review sessions
- Active-recall based learning
- Support for maintaining knowledge across multiple domains
